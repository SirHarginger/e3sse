# Results Validation

Do not validate a scientific result only by checking that code ran.

Check:

- units;
- sample counts;
- missing/excluded observations;
- expected signs and physical ranges;
- split integrity;
- leakage;
- raw versus corrected identities;
- uncertainty calculation;
- reproducibility metadata;
- agreement of independent implementations for selected cases;
- suspicious outliers and failure clusters.

Distinguish coding defects, data defects, numerical instability, model error,
and genuine scientific findings.
